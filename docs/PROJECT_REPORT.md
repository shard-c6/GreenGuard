## 🛠️ Technical Difficulties & Solutions

### 1. Achieving Visual Parity Across Authentication
- **Challenge**: The new landing page was significantly more advanced than the older auth pages, creating a jarring experience.
- **Solution**: Developed a shared `AtmosphericBackground` component and a unified CSS design system (`globals.css`) using curated HSL color palettes. Forced "active" states on background elements during auth flows to maintain a premium feel even on simpler forms.

### 2. Map Interface (400 Bad Request)
- **Challenge**: The plant discovery map was intermittently failing with 400 errors during geospatial queries.
- **Solution**: Traced the issue to a mismatch between frontend coordinate formatting and backend PostGIS expectations. Resolved by strictly typing the `LatLng` objects and updating the `mapPlantations` controller to handle edge cases where location data might be partially null.

### 3. Managing Multi-Module State
- **Challenge**: Keeping `frontend`, `backend`, and `flora-genius` synchronized during rapid development.
- **Solution**: Implemented a centralized API service layer in the frontend with strict TypeScript interfaces. This ensured that any change in the backend schema was immediately caught as a build error in the frontend.

### 4. Performance of Atmospheric Effects
- **Challenge**: Complex glassmorphism and animations caused frame drops on mid-range devices.
- **Solution**: Optimized the `AtmosphericBackground` by using CSS hardware acceleration (`will-change: transform`) and limiting the number of active SVG filters. Replaced heavy JS-based animations with optimized Framer Motion variants.
